# SATR ns-3 Simulation Overlay

This repository contains the custom files for the SATR simulation built on
ns-3.47. It is intentionally not a fork of the complete ns-3 source tree:
upstream ns-3 files, build products, and local environments are excluded from
version control.

## Repository Layout

- `contrib/SATR/`: SATR model, topology, controller, routing, metrics, tests,
  examples, experiment scripts, result extractors, and plotting tools.
- `scratch/satr-runner.cc`: the main ns-3 experiment entry point.
- `results/`: retained experiment logs, summaries, and paper figures.

## Prepare ns-3.47

Obtain a clean ns-3.47 source tree and clone this repository separately:

```bash
git clone --branch ns-3.47 https://gitlab.com/nsnam/ns-3-dev.git ns-3.47
git clone https://github.com/yoooo-Derek/simulation.git satr-overlay

cp -a satr-overlay/contrib/SATR ns-3.47/contrib/
cp satr-overlay/scratch/satr-runner.cc ns-3.47/scratch/
cd ns-3.47
```

Configure and build with tests enabled:

```bash
./ns3 configure --enable-examples --enable-tests
./ns3 build
./test.py -s satr-core
```

## Run the Simulation

Run one strategy directly:

```bash
./ns3 run "satr-runner --strategy=SATR --offeredLoad=0.2"
```

Supported strategy values are `SATR`, `TrafficFair`, `ESP`, `on-demand`, and
`static`. `TrafficFair` is labeled TFA in the paper plots.

Run a small three-strategy matrix and generate summary CSV files:

```bash
contrib/SATR/tools/run-satr-matrix.sh \
  --mode=pilot \
  --strategies=SATR,TrafficFair,ESP \
  --offeredLoads=0.2,0.8 \
  --outputDir=results/satr/pilot
```

The matrix script writes one log and runtime file per run, then invokes:

- `aggregate-satr-results.py`
- `extract-satr-performance-summary.py`
- `extract-satr-utilization-summary.py`

## Plot Results

The plotting scripts require Python 3, pandas, and Matplotlib. Times New Roman
is preferred when installed; the scripts fall back to another serif font when
it is unavailable.

For a `performance-summary.csv` produced by the current runner:

```bash
python3 contrib/SATR/tools/plot_fct.py \
  --csv results/satr/pilot/performance-summary.csv

python3 contrib/SATR/tools/plot_satr_throughput.py \
  --csv results/satr/pilot/performance-summary.csv

python3 contrib/SATR/tools/plot_satr_link_utilization.py \
  --csv results/satr/pilot/performance-summary.csv
```

Each plotting command supports `--out-dir`, `--out-prefix`, `--panel-label`,
and `--pdf-only`.

## Legacy Result Provenance

The files under
`results/smtra/ai-structural-decoy-three-strategy-performance-stop1p4/` and
the PDFs under `results/tables/fig4/` and `results/tables/fig4-new/` are
retained paper artifacts generated by the earlier SMTRA implementation.
Their logs use legacy strategy and workload fields such as
`strong-topk-background-shortest` and `matrixMode=observe-test`.

The current SATR runner has a different command-line and output schema.
Consequently, these legacy artifacts are available for inspection and numeric
comparison, but they cannot be reproduced exactly from the current SATR
runner. New experiments should be written under `results/satr/`.
